# Code PR 与 Spec 一致性清单

## 追溯信息

- [ ] PR 引用了 Spec 目录。
- [ ] PR 记录了开发使用的 Spec 基线提交。
- [ ] PR 列出了本次覆盖的任务和验收标准。
- [ ] 开发期间的 Spec 变更 PR 已建立链接。

## 实现一致性

- [ ] 代码行为符合当前已批准 Spec。
- [ ] 没有实现 Spec 非目标中的能力。
- [ ] 没有以迁就当前代码为理由反向修改业务要求。
- [ ] AI 或人工修改没有超出任务声明的影响范围。

## 验证证据

- [ ] 每条相关验收标准都有测试或人工验证证据。
- [ ] 单元、集成和回归测试均按设计执行。
- [ ] 异常、权限和边界行为已验证。
- [ ] 验证命令、结果和已知限制记录完整。

## 开发中新问题

- [ ] L0 问题通过代码和测试修复，没有错误修改 Spec。
- [ ] L1 决策已写入 `design.md` 或 `decisions.md`。
- [ ] L2 变更已经先完成 Spec 评审和批准。
- [ ] 有效聊天或会议结论均已回写仓库。
