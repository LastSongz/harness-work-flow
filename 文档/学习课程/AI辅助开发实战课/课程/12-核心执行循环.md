# 核心执行循环：检查→修改→运行→读结果→修正→停止

导航：上一篇 [[11-AI与TDD]] · [[VibeCoding课程首页]] · [[VibeCoding课程总纲]] · 下一篇 [[13-证据驱动调试]]

> [!summary] 核心问题
> 高质量 AI 开发不是一次生成，而是不断缩小未知范围：检查现状、做最小修改、运行工具、阅读结果、修正判断，并在证据充分时停止。任何一步缺失，都可能让 Agent 在错误方向上加速。


## 每一轮都要减少不确定性

核心循环不是“反复让 Agent 修到通过”，而是：

1. **检查**：读取当前文件、Diff、测试和错误，形成一个可证伪假设。
2. **修改**：只做验证该假设所需的最小变化。
3. **运行**：执行最窄但真实的反馈命令。
4. **读结果**：查看退出码、失败测试、堆栈和 Diff，不只读最后一行。
5. **修正**：根据新证据继续、撤销局部实验或更新 Plan。
6. **停止**：验收满足，或触发权限/范围/环境停止条件。

命令通过也不等于完成：测试可能没被发现，Diff 可能混入无关修改，或验收场景根本没覆盖。命令失败也不一定是代码错误，可能是依赖、网络、数据或基线本来就红。

## 结果分类

| 结果 | 下一步 |
|---|---|
| 预期失败 | 证明 Red 有效，进入最小实现 |
| 意外失败 | 暂停实现，先区分基线/环境/新代码 |
| 目标测试通过 | 扩大到相邻测试和静态检查 |
| 全部检查通过但 Diff 超范围 | 收窄 Diff，再验证 |
| 需要迁移或新权限 | 停止，回到 Plan/审批 |
| 连续两轮无新证据 | 停止盲试，重写假设或开新会话 |

## 一轮执行日志

```markdown
目标：让 PAID 订单请求取消后写入一个退款 outbox。

检查：
- PaidOrderCancellationTest 失败：outbox 数量期望 1，实际 0。
- Order 已进入 CANCELING；事务服务尚未处理 CancelDecision。

假设：
- 应用服务漏掉了 decision.refundRequired() 分支。

最小修改：
- 在 CancelOrderUseCase 内构造并保存 RefundRequestedOutbox；
- 不实现 Worker，不改 Controller。

运行：
./mvnw -Dtest=PaidOrderCancellationTest test

结果：
- 目标测试通过；新增 34 行，修改 2 个生产文件和 1 个测试文件。

扩大验证：
./mvnw -Dtest=OrderTest,CancelOrderUseCaseTest test

停止判断：
- 当前切片验收通过；数据库唯一键仍属于下一个集成切片。
```

## 可以怎样做

1. 每轮开始写一句目标和一个假设。
2. 在修改前记录目标命令与预期结果。
3. 限定文件和符号范围。
4. 运行后先读退出码与原始错误，再让 Agent解释。
5. 查看 Diff 是否与本轮假设一致。
6. 目标测试通过后逐级扩大验证。
7. 达到切片验收立即停止，不顺手扩展功能。

## 动手梳理

以下情况发生后，你会继续、回到 Plan 还是停止请求批准？

- 单元测试通过，但必须新增 outbox 表。
- 测试报公司制品库 401，代码尚未编译。
- 目标测试通过，Agent 又格式化了 40 个无关文件。
- 同一错误修改三次，堆栈没有变化。

合理判断：第一项停止并走迁移评审；第二项先处理环境/权限；第三项收窄 Diff；第四项停止盲试，重新诊断。

## 自查清单

- [ ] 一轮只有一个主要假设。
- [ ] 修改范围与假设直接相关。
- [ ] 保存了命令、退出结果和关键错误。
- [ ] 通过后逐级扩大验证并审查 Diff。
- [ ] 触发停止条件时没有继续扩大修改。

## 实战速查卡

### 什么时候查这篇文章

- Agent 连续修改却不运行命令。
- 命令失败后盲目重试。
- 一轮改动包含多个假设。
- 任务已经满足验收却继续优化。

### 先做什么

- 检查基线和当前 Diff。
- 只修改一个可解释切片。
- 运行最窄相关验证。
- 逐行阅读原始结果。
- 根据证据修正或停止。

### 可直接借鉴的方法

检查 → 修改 → 运行 → 读结果 → 修正 → 停止。每一轮记录假设、动作、命令、结果和下一步，确保不确定性真的减少。

### 常见误区

- 一次改多个变量。
- 只看命令退出码不读输出。
- 失败后扩大修改范围。
- 没有停止条件。
- 把“模型认为完成”当证据。

### 完成证据

- 逐轮执行日志。
- 每轮单一假设和窄 Diff。
- 原始命令输出。
- 满足验收后的停止说明与剩余风险。
